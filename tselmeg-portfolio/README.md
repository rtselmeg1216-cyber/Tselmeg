# Tselmeg R. — Personal Portfolio

A one-page personal portfolio website: about, academics, volleyball, experience, dreams, off-duty life, a photo gallery and contact.

## Folder structure

```
tselmeg-portfolio/
├── index.html          # the whole website (HTML + CSS)
├── README.md
└── images/
    ├── family.jpg
    ├── volleyball-team.jpg
    ├── volleyball-medals.jpg
    ├── bouldering.jpg
    ├── hallway-selfie.jpg
    └── silly-face.jpg
```

## View it locally

Open `index.html` in any web browser. Keep the `images/` folder next to it.

## Publish free with GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. After a minute your site is live at `https://<your-username>.github.io/<repo-name>/`.
